# System Requirement — Module: สาขา (Branch)

## FR-BRN-001: จัดการ Branch
- เพิ่ม, แก้ไข, ปิดชั่วคราว, ปิดถาวร Branch ได้
- รองรับทั้งสาขาปกติ (type=branch) และคลังกลาง (type=warehouse) — **ทั้งคู่เป็น stock location เท่ากัน; 1 Branch = 1 สต็อก** (คลังกลางคือ Branch ที่ไม่ผูกกับสาขาปกติ ใช้กลไก StockBalance/StockLot/Transfer เดียวกัน)
- บันทึกข้อมูล: ชื่อ, ที่อยู่, เบอร์, เวลาเปิด-ปิด (สาขาปกติเท่านั้น)
- ปิด Branch ได้เฉพาะเมื่อไม่มีกะเปิด, ไม่มีออเดอร์ pending, และไม่มีสต็อกคงเหลือ (หรือได้โอนสต็อกออกไป Branch อื่นแล้ว)

## FR-BRN-002: ตั้งค่า Branch
- ตั้งค่าเวลาเปิด-ปิด (เฉพาะสาขาปกติ)
- ตั้งค่าขั้นต่ำสต็อกแยกตาม Branch (รวมคลังกลาง)
- override config แต้มสมาชิกต่อสาขา (เฉพาะสาขาปกติ)

## FR-BRN-003: จัดการโซน
- เพิ่ม/แก้ไข/ลบโซนในสาขา
- ใช้สำหรับจัดระเบียบพื้นที่

## FR-BRN-004: สิทธิ์ Branch
- พนักงานเข้าถึงได้เฉพาะ Branch ที่ได้รับมอบหมาย (สาขา หรือ คลังกลาง)
- แอดมินเห็นทุก Branch เสมอ
- เจ้าของเห็นทุก Branch เสมอ

---

## Permission
| Action | เจ้าของ | แอดมิน | พนักงาน |
|--------|---------|--------|---------|
| เพิ่ม/ลบ Branch | ✓ | ✗ | ✗ |
| แก้ไข Branch | ✓ | ✓ | ✗ |
| ดู Branch ทั้งหมด | ✓ | ✓ | เฉพาะ Branch ที่ได้รับมอบหมาย |
