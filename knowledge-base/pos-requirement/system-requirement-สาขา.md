# System Requirement — Module: สาขา (Branch)

## FR-BRN-001: จัดการสาขา
- เพิ่ม, แก้ไข, ปิดชั่วคราว, ปิดถาวรสาขาได้
- รองรับทั้งสาขาปกติและคลังกลาง
- บันทึกข้อมูล: ชื่อ, ที่อยู่, เบอร์, เวลาเปิด-ปิด
- ปิดสาขาได้เฉพาะเมื่อไม่มีกะเปิดและไม่มีออเดอร์ pending

## FR-BRN-002: ตั้งค่าสาขา
- ตั้งค่าเวลาเปิด-ปิด
- ตั้งค่าขั้นต่ำสต็อกแยกตามสาขา
- override config แต้มสมาชิกต่อสาขา

## FR-BRN-003: จัดการโซน
- เพิ่ม/แก้ไข/ลบโซนในสาขา
- ใช้สำหรับจัดระเบียบพื้นที่

## FR-BRN-004: สิทธิ์สาขา
- พนักงานเข้าถึงได้เฉพาะสาขาที่มีสิทธิ์
- แอดมินเห็นทุกสาขาเสมอ
- เจ้าของเห็นทุกสาขาเสมอ

---

## Permission
| Action | เจ้าของ | แอดมิน | พนักงาน |
|--------|---------|--------|---------|
| เพิ่ม/ลบสาขา | ✓ | ✗ | ✗ |
| แก้ไขสาขา | ✓ | ✓ | ✗ |
| ดูสาขาทั้งหมด | ✓ | ✓ | เฉพาะสาขาตัวเอง |
