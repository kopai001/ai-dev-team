# System Requirement — Module: กะการทำงาน (Shift)

## FR-SHF-001: เปิดกะ
- ระบบต้องให้พนักงานเปิดกะก่อนเริ่มขาย
- พนักงานเห็นเฉพาะข้อมูลกะของตัวเอง — ไม่แสดงยอดเงินในเก๊ะที่พนักงานกะก่อนหน้าบันทึกไว้
- รองรับการนับเงินตั้งต้นแยกตามชนิดธนบัตร/เหรียญ (พนักงานนับเองโดยไม่มียอดส่งมอบแสดง)
- คำนวณยอดรวมอัตโนมัติจากชนิดที่กรอก
- บล็อกการเปิดกะซ้ำเฉพาะพนักงานคนเดียวกัน (ห้ามเปิดกะที่ 2 ถ้าตัวเองมีกะ open อยู่)
- พนักงานกะถัดไปเปิดกะได้แม้พนักงานกะก่อนหน้ายังไม่ปิดกะ
- **[Admin Badge] ยอดเงินไม่ตรง:** หากยอดปิดกะของกะก่อนหน้า ≠ ยอดเปิดกะของกะถัดมา ระบบแสดง badge แจ้งเตือนแอดมิน ทั้งสองกะ
- **[Admin Badge] กะไม่ปิด:** หากมีกะที่ยังไม่ปิดและกะถัดไปได้เปิดแล้ว ระบบแสดง badge แจ้งเตือนแอดมิน
- แอดมินสามารถดูยอดเงินเปิด/ปิดกะของพนักงานทุกคนได้

## FR-SHF-002: บันทึกค่าใช้จ่ายระหว่างกะ
- บันทึกค่าใช้จ่ายได้ตลอดกะ
- เลือกประเภทค่าใช้จ่ายจาก preset หรือกรอกเอง
- ค่าใช้จ่ายหักจากยอดเงินสดคาดหวัง (expected cash)
- ดูรายการค่าใช้จ่ายสะสมในกะ

## FR-SHF-003: ส่งเงิน (Cash Remittance)
- ส่งเงินได้ระหว่างกะหรือตอนปิดกะ
- เลือกช่องทาง: ฝากคนขับ, โอน, อื่นๆ
- แนบรูปหลักฐานการส่ง
- สถานะ "รอยืนยัน" จนแอดมินยืนยัน
- แอดมินยืนยันหรือปฏิเสธพร้อมเหตุผล

## FR-SHF-004: ปิดกะ
- นับเงินสดปิดกะแยกตามชนิด
- ระบบคำนวณยอดที่ควรมีอัตโนมัติ
- แสดงผลต่าง (ขาด/เกิน/ตรง) พร้อมไฮไลต์
- บังคับระบุสาเหตุถ้าผลต่างเกิน threshold ที่ตั้งค่า
- ยอดปิดกะถูกส่งเป็นยอดเปิดกะถัดไปอัตโนมัติ

## FR-SHF-005: รายงานกะ
- ดูรายงานกะแต่ละกะได้
- แสดง: ยอดขาย, ยอดเงินสด, ยอดโอน, ค่าใช้จ่าย, ผลต่าง
- เจ้าของและแอดมินเห็นยอดเงินกะของทุกสาขา พนักงานเห็นเฉพาะกะตัวเอง
- Export รายงานกะเป็นไฟล์

## FR-SHF-006: รายงานยอดเงินไม่ตรง
- พนักงานส่งรายงานยอดไม่ตรงได้
- ระบุ: ยอดที่ควรมี, นับได้, สาเหตุ, หลักฐาน
- แอดมินรับแจ้งเตือนและตรวจสอบ
- บันทึกผลการตรวจสอบ

## Non-Functional Requirements

### Calculation Accuracy
- ยอดเงินทุกตัวเลขต้องแม่นยำ 2 ทศนิยม
- ป้องกัน floating-point error ด้วย Decimal type

### Performance
- โหลดหน้าเปิดกะภายใน 1 วินาที
- ปิดกะและบันทึกสำเร็จภายใน 3 วินาที

### Permission
| Action | เจ้าของ | แอดมิน | พนักงาน |
|--------|---------|--------|---------|
| เปิด/ปิดกะ | ✓ (ทุกสาขา) | ✓ (ทุกสาขา) | ✓ (เฉพาะสาขาตัวเอง) |
| บันทึกค่าใช้จ่าย | ✓ (ทุกสาขา) | ✓ (ทุกสาขา) | ✓ (เฉพาะสาขาตัวเอง) |
| ส่งเงิน | ✓ (ทุกสาขา) | ✓ (ทุกสาขา) | ✓ (เฉพาะสาขาตัวเอง) |
| ยืนยันการส่งเงิน | ✓ (ทุกสาขา) | ✓ (ทุกสาขา) | ✗ |
| ดูรายงานกะ | ✓ (ทุกสาขา) | ✓ (ทุกสาขา) | เฉพาะกะตัวเอง |
| ดูยอดเงินในเก๊ะ (เปิด/ปิดกะ) ของพนักงานทุกคน | ✓ (ทุกสาขา) | ✓ (ทุกสาขา) | ✗ |
| ดู badge แจ้งเตือนกะไม่ปิด / ยอดเงินไม่ตรง | ✓ (ทุกสาขา) | ✓ (ทุกสาขา) | ✗ |

### Security
- ยอดเงินแสดงเต็มเฉพาะเจ้าของและแอดมิน
- แอดมินทุกคนเข้าถึงได้ทุกสาขา (ไม่จำกัดเฉพาะสาขาตัวเอง)
- บันทึก audit log ทุก action ใน module กะ
