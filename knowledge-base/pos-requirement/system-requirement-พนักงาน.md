# System Requirement — Module: พนักงาน (Employee)

## FR-EMP-001: จัดการข้อมูลพนักงาน
- เพิ่ม, แก้ไข, ระงับ, ปิดบัญชีพนักงานได้
- บันทึกข้อมูล: ชื่อ, นามสกุล, ชื่อเล่น, เบอร์โทร, วันเริ่มงาน
- ระบบสร้าง username/password อัตโนมัติเมื่อเพิ่มพนักงาน
- ปิดบัญชีเป็น soft delete (ข้อมูลยังอยู่)

## FR-EMP-002: บทบาทและสิทธิ์
- กำหนดบทบาท: owner/admin/staff ต่อสาขา
- ตั้งสิทธิ์ละเอียดต่อ module (ดู/แก้ไข/ลบ)
- พนักงาน 1 คนมีสิทธิ์ต่างสาขาได้
- สิทธิ์ใหม่มีผลทันทีโดยไม่ต้อง re-login

## FR-EMP-003: ตารางกะรายสัปดาห์
- จัดตารางกะพนักงานรายสัปดาห์ในปฏิทิน grid
- คัดลอกตารางไปสัปดาห์ถัดไปได้
- ดูตารางย้อนหลังได้
- พนักงานรับแจ้งเตือนเมื่อตารางกะถูกอัปเดต

## FR-EMP-004: ประวัติพนักงาน
- ดูประวัติการทำงาน, กะที่ผ่านมา, การแก้ไขข้อมูล
- ค้นหาพนักงานด้วยชื่อ, สาขา, สถานะ

---

## Permission
| Action | เจ้าของ | แอดมิน | พนักงาน |
|--------|---------|--------|---------|
| เพิ่ม/ลบพนักงาน | ✓ | ✗ | ✗ |
| แก้ไขข้อมูล | ✓ | ✓ (ทุกสาขา) | ✗ |
| กำหนดสิทธิ์ | ✓ | ✗ | ✗ |
| จัดตารางกะ | ✓ | ✓ | ✗ |
| ดูประวัติ | ✓ | ✓ | เฉพาะตัวเอง |

## Security
- password ต้องถูก hash (bcrypt/argon2)
- ล็อค account หลัง login ผิด 5 ครั้ง
- Session timeout: 8 ชั่วโมง (หรือจนปิดกะ)
- บันทึก audit log ทุกการเปลี่ยนสิทธิ์
