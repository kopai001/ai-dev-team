# Flow — Module: โยกย้ายสต็อก

## ภาพรวม
Module จัดการการโอนสินค้าระหว่างสาขา และระหว่างสาขากับคลังกลาง พร้อมระบบขออนุมัติตัดสต็อก

---

## Flow 1: สร้างรายการโยกย้าย

```
[หน้าโยกย้าย] → "สร้างรายการโยกย้ายสต็อก"
  │
  ▼
กำหนด:
  ├─ ต้นทาง (สาขา/คลังกลาง)
  └─ ปลายทาง (สาขา/คลังกลาง)
  │
  ▼
เพิ่มสินค้า:
  ├─ ค้นหาสินค้า
  ├─ กำหนดจำนวน + หน่วย
  └─ ระบุหมายเหตุ (ไม่บังคับ)
  │
  ▼
ตรวจสอบสต็อกต้นทาง:
  ├─ [พอ] → ดำเนินการต่อ
  └─ [ไม่พอ] → แจ้งเตือน "เกินสต็อกต้นทาง" (ยังส่งคำขอได้)
  │
  ▼
กด "ส่งคำขออนุมัติ"
  │
  ▼
แอดมินรับแจ้งเตือน → รอการอนุมัติ
```

---

## Flow 2: อนุมัติ/ปฏิเสธรายการโยกย้าย (แอดมิน)

```
[แอดมิน] รับแจ้งเตือน "มีคำขอโยกย้ายรอการอนุมัติ"
  │
  ▼
[หน้าจัดการคำขอ] → ดูรายการ
  │
  ├─ กด "อนุมัติ"
  │   ├─ ตัดสต็อกที่ต้นทางทันที
  │   ├─ สถานะ = "รอรับ" (ที่ปลายทาง)
  │   └─ แจ้งสาขาปลายทาง
  │
  └─ กด "ปฏิเสธ"
      ├─ ระบุเหตุผล (บังคับ)
      ├─ สต็อกไม่เปลี่ยนแปลง
      └─ แจ้งผู้ขอ
```

---

## Flow 3: รับสินค้าที่ปลายทาง

```
[สาขาปลายทาง] รับแจ้งเตือน "มีสินค้ามาถึง"
  │
  ▼
[หน้ารับของ] → เลือกรายการโยกย้ายที่รอรับ
  │
  ▼
ตรวจสอบสินค้า:
  ├─ กรอกจำนวนที่รับจริง (อาจต่างกัน — สูญหายระหว่างทาง)
  └─ ถ่ายรูปหลักฐาน (ไม่บังคับ)
  │
  ▼
กด "ยืนยันรับของทั้งหมด"
  │
  ├─ [รับครบ] → สต็อกปลายทางเพิ่ม → บันทึกเรียบร้อย
  └─ [รับไม่ครบ] → บันทึก "รับขาด" → ระบบแจ้งส่วนต่างให้แอดมิน
```

---

## Flow 4: ดูประวัติโยกย้ายทั้งหมด

```
[หน้าประวัติโยกย้าย]
  │
  ├─ กรองด้วย: ต้นทาง, ปลายทาง, วันที่, สถานะ
  ├─ ดูรายละเอียดแต่ละรายการ
  └─ Export รายงาน
```

---

## สถานะรายการโยกย้าย

```
[pending]     → รอแอดมินอนุมัติ
    ↓ อนุมัติ
[approved]    → สต็อกต้นทางถูกตัด รอรับที่ปลายทาง
    ↓ ปลายทางรับ
[completed]   → สต็อกปลายทางเพิ่ม ครบกระบวนการ
    ↓ หรือปฏิเสธ
[rejected]    → ยกเลิก สต็อกไม่เปลี่ยน
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| สต็อกต้นทางไม่พอ | แจ้งเตือน แต่ยังส่งคำขอได้ (แอดมินตัดสินใจ) |
| รับสินค้าน้อยกว่าที่โอน | บันทึก "ส่วนต่าง" แจ้งแอดมิน |
| ยกเลิกรายการที่อนุมัติแล้ว | ต้องมีสิทธิ์พิเศษ + คืนสต็อกต้นทาง |
| โอนจากสาขาที่ปิดอยู่ | บล็อก แจ้งเตือน |
