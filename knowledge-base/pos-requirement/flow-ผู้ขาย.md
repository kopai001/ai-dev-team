# Flow — Module: ผู้ขาย (Supplier)

## ภาพรวม
Module จัดการข้อมูลผู้ขาย (supplier/ยี่ปั๊ว) และบันทึกประวัติการซื้อสินค้าจากผู้ขายแต่ละราย

---

## Flow 1: เพิ่มผู้ขายใหม่

```
[หน้าผู้ขาย] → "บันทึกผู้ขายใหม่"
  │
  ▼
กรอกข้อมูล:
  ├─ ชื่อผู้ขาย (บังคับ)
  ├─ ชื่อผู้ติดต่อ
  ├─ เบอร์โทร
  ├─ ที่อยู่
  └─ หมายเหตุ
  │
  ▼
กด "บันทึกผู้ขาย" → สำเร็จ
```

---

## Flow 2: แก้ไขข้อมูลผู้ขาย

```
[หน้าผู้ขาย] → ค้นหาผู้ขาย → เลือกผู้ขาย
  │
  ▼
[หน้ารายละเอียดผู้ขาย]
  ├─ "แก้ไขข้อมูล" → แก้ไข → "บันทึก"
  └─ ดูประวัติการซื้อจากผู้ขายรายนี้
```

---

## Flow 3: บันทึกการซื้อสินค้าจากผู้ขาย

```
[หน้ารับของ] → เลือกผู้ขาย
  │
  ▼
เพิ่มสินค้าที่ซื้อ:
  ├─ ค้นหาสินค้า
  ├─ กรอกจำนวน + หน่วย
  ├─ กรอกราคาทุนต่อหน่วย
  └─ ระบุวันหมดอายุ (ถ้ามี)
  │
  ▼
แนบรูปหลักฐาน (ใบส่งของ) → ไม่บังคับ
  │
  ▼
กด "บันทึกรับของ"
  ├─ สำเร็จ → สต็อกเพิ่ม + บันทึกประวัติผู้ขาย
  └─ ล้มเหลว → แจ้งข้อผิดพลาด
```

---

## Flow 4: ดูประวัติการซื้อ

```
[หน้าผู้ขาย] → เลือกผู้ขาย → "ประวัติรับเข้า"
  │
  ▼
แสดงรายการ:
  ├─ วันที่รับ
  ├─ รายการสินค้า + จำนวน
  ├─ ราคาทุนรวม
  └─ พนักงานที่รับ
  │
  ▼
กรองด้วยช่วงวันที่ → Export
```

---

## Flow 5: ค้นหาและกรองผู้ขาย

```
[หน้าผู้ขาย]
  ├─ ค้นหาด้วยชื่อผู้ขาย
  ├─ กรองด้วยสินค้าที่ขาย
  └─ เรียงตาม: ชื่อ, วันที่ซื้อล่าสุด, ยอดซื้อรวม
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| ชื่อผู้ขายซ้ำ | แจ้งเตือน แต่บันทึกได้ (ไม่ block) |
| ลบผู้ขายที่มีประวัติ | ปิดใช้งานแทนลบ (soft delete) |
