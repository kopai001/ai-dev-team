# Flow — Module: พนักงาน (Employee)

## ภาพรวม
Module จัดการข้อมูลพนักงาน, บทบาทและสิทธิ์การเข้าถึง, และตารางกะประจำสัปดาห์

---

## Flow 1: เพิ่มพนักงานใหม่

```
[แอดมิน/เจ้าของ] → "เพิ่มพนักงานใหม่"
  │
  ▼
กรอกข้อมูล:
  ├─ ชื่อ-นามสกุล (บังคับ)
  ├─ ชื่อเล่น
  ├─ เบอร์โทร
  ├─ วันที่เริ่มงาน
  ├─ บทบาท (Role): admin/staff
  └─ สาขาที่รับผิดชอบ (เลือกได้หลายสาขา)
  │
  ▼
ระบบสร้างบัญชีเข้าสู่ระบบให้
  │
  ▼
ตั้งสิทธิ์การเข้าถึง:
  ├─ สิทธิ์ต่อ module (ดู/แก้ไข)
  └─ สาขาที่เข้าถึงได้
  │
  ▼
บันทึก → แจ้งพนักงาน
```

---

## Flow 2: แก้ไขข้อมูลพนักงาน

```
[หน้าจัดการพนักงาน] → ค้นหาพนักงาน → เลือก
  │
  ▼
แก้ไข:
  ├─ ข้อมูลส่วนตัว
  ├─ บทบาท/สิทธิ์
  └─ สาขาที่รับผิดชอบ
  │
  ▼
กด "บันทึก" → บันทึกประวัติการแก้ไข
```

---

## Flow 3: ระงับ/ปิดบัญชีพนักงาน

```
[หน้าพนักงาน] → เลือกพนักงาน
  │
  ├─ "ระงับสิทธิ์" → พนักงาน Login ไม่ได้ชั่วคราว
  │   └─ "คืนสิทธิ์" → กลับสู่ปกติ
  │
  └─ "ลาออก" → ปิดบัญชีถาวร (soft delete)
      └─ ประวัติยังคงอยู่ในระบบ
```

---

## Flow 4: ตารางกะพนักงาน (Weekly Schedule)

```
[แอดมิน] → "จัดตารางกะพนักงาน"
  │
  ▼
เลือกสัปดาห์ที่ต้องการจัด
  │
  ▼
ตารางแสดง: แนวตั้ง = วัน (จ-อา), แนวนอน = พนักงาน
  │
  ▼
คลิกช่องตาราง → เลือกกะ (เช้า/บ่าย/ดึก/หยุด)
  │
  ▼
"คัดลอกไปสัปดาห์ถัดไป" → คัดลอกตารางเดิม
  │
  ▼
บันทึก → พนักงานรับแจ้งเตือนตารางกะ
```

---

## Flow 5: ดูประวัติพนักงาน

```
[หน้าพนักงาน] → เลือกพนักงาน
  │
  ▼
ดู:
  ├─ ประวัติการทำงาน (กะที่ผ่านมา)
  ├─ ประวัติการแก้ไขข้อมูล
  ├─ วันที่เริ่มงาน, สาขาที่ผ่านมา
  └─ บทบาทที่เคยได้รับ
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| พนักงานถูกระงับแต่มีกะเปิดอยู่ | แจ้งเตือน ต้องปิดกะก่อน |
| แก้ไขสิทธิ์พนักงานที่กำลัง Login | สิทธิ์ใหม่มีผลทันที (force refresh) |
| ลบสาขาที่พนักงานรับผิดชอบ | แจ้งเตือน ต้อง reassign ก่อน |
