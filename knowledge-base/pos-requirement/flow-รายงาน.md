# Flow — Module: รายงาน (Reports)

## ภาพรวม
Module รายงานสำหรับเจ้าของร้านและแอดมิน ครอบคลุม: ยอดขาย, สต็อก, กะ, พนักงาน, สมาชิก และกำไร

---

## Flow 1: รายงานยอดขาย

```
[เจ้าของ/แอดมิน] → หน้ารายงาน → "ยอดขาย"
  │
  ▼
เลือกมุมมอง:
  ├─ รายวัน (สรุปรายวัน)
  ├─ รายสัปดาห์
  └─ รายเดือน
  │
  ▼
เลือกสาขา: ทุกสาขา หรือ เลือกสาขา
  │
  ▼
แสดง:
  ├─ ยอดขายรวม
  ├─ จำนวนบิล
  ├─ บิลเฉลี่ย
  ├─ ยอดขายแยกช่องทางชำระ (สด/โอน)
  ├─ กำไรสุทธิ
  ├─ กราฟยอดขายรายวัน
  └─ ยอดขายแยกสาขา (ถ้าดูรวม)
```

---

## Flow 2: รายงานสต็อก

```
[เจ้าของ/แอดมิน] → "รายงานสต็อก"
  │
  ▼
เลือก:
  ├─ ภาพรวมสต็อก (สต็อกสุขภาพ)
  ├─ ตารางสต็อกเปรียบเทียบ (ทุกสาขา)
  ├─ สินค้าขายดี
  └─ สินค้าขายช้า / ใกล้หมดอายุ
  │
  ▼
แสดงข้อมูลในตาราง + Export
```

---

## Flow 3: รายงานกะ

```
[เจ้าของ] → "รายงานกะ"
  │
  ▼
เลือก: สาขา, ช่วงวันที่, กะ
  │
  ▼
แสดง:
  ├─ ยอดเงินเปิดกะ / ปิดกะ
  ├─ ยอดขายในกะ
  ├─ ยอดโอน
  ├─ ค่าใช้จ่าย
  ├─ ผลต่างเงิน (ขาด/เกิน)
  └─ รายงานยอดเงินไม่ตรง (ถ้ามี)
```

---

## Flow 4: รายงานพนักงาน

```
[เจ้าของ] → "รายงานพนักงาน"
  │
  ▼
แสดง:
  ├─ จำนวนกะที่ทำงาน
  ├─ ยอดขายต่อพนักงาน
  ├─ ประวัติกะ
  └─ ค่าแรงรายวัน (ถ้าตั้งค่าไว้)
```

---

## Flow 5: รายงานสมาชิก

```
[เจ้าของ/แอดมิน] → "รายงานสมาชิก"
  │
  ▼
แสดง:
  ├─ สมาชิกใหม่เดือนนี้
  ├─ สมาชิกที่ซื้อบ่อย
  ├─ ยอดซื้อต่อสมาชิก
  ├─ แต้มสะสมรวม
  └─ วิเคราะห์ตะกร้าสินค้าสมาชิก
```

---

## Flow 6: Export รายงาน

```
[ทุกหน้ารายงาน]
  │
  └─ กด "รายงานเป็นไฟล์"
      ├─ PDF
      └─ Excel/CSV
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| ยอดขายวันที่ไม่มีบิล | แสดง 0 (ไม่ข้ามวัน) |
| สาขาที่ปิดไปแล้ว | แสดงในรายงานย้อนหลังได้ แต่ไม่ขาย |
| Export ข้อมูลมาก | background job + notify เมื่อเสร็จ |
