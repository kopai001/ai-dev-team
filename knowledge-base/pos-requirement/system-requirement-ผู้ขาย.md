# System Requirement — Module: ผู้ขาย (Supplier)

## FR-SUP-001: จัดการผู้ขาย
- เพิ่ม, แก้ไข, ปิดใช้งานผู้ขายได้
- ค้นหาผู้ขายด้วยชื่อหรือเบอร์โทร
- ปิดใช้งาน (soft delete) แทนการลบถาวร

## FR-SUP-002: บันทึกการซื้อ
- เลือกผู้ขายเมื่อรับสินค้าเข้าสต็อก
- บันทึกราคาทุนต่อรายการ
- แนบรูปหลักฐาน (ใบส่งของ) ได้

## FR-SUP-003: ประวัติการซื้อ
- ดูประวัติรับสินค้าจากผู้ขายแต่ละราย
- กรองด้วยช่วงวันที่
- Export ประวัติเป็นไฟล์
