# Flow — Module: กะการทำงาน (Shift Management)

## ภาพรวม
Module ควบคุมวงจรกะการทำงาน: เปิดกะ → ขาย → ส่งเงิน → ปิดกะ พร้อมระบบตรวจสอบยอดเงินและรายงานกะ

---

## Flow 1: เปิดกะ

```
พนักงาน Login → ระบบตรวจสอบ
  │
  ├─ [ตัวเองมีกะ open อยู่] → เข้าสู่หน้าขายทันที
  │
  └─ [ตัวเองไม่มีกะ open] → แสดงหน้า "เปิดกะ"
      ├─ [กะก่อนหน้า (พนักงานอื่น) ยังไม่ปิด] → อนุญาตให้เปิดกะได้ตามปกติ
      │   └─ ระบบ flag กะก่อนหน้าว่า "ไม่มีการปิดกะ" → badge แจ้งแอดมิน
      │
      ├─ นับเงินสดตั้งต้น (กรอกจำนวนต่อชนิด) — ไม่แสดงยอดเงินจากกะก่อนหน้า
      ├─ ระบบคำนวณยอดรวมอัตโนมัติ
      └─ กด "ยืนยันเปิดกะ" → กะเปิด → เริ่มขายได้

[ระบบ — เบื้องหลัง] หลังเปิดกะสำเร็จ:
  ├─ เปรียบเทียบ opening_cash (กะนี้) vs closing_cash_counted (กะก่อนหน้า)
  └─ ถ้าไม่ตรง → badge "ยอดเงินไม่ตรง" แจ้งแอดมิน
```

---

## Flow 2: ระหว่างกะ (ขาย + จัดการเงิน)

```
[ระหว่างกะ]
  │
  ├─ ขายสินค้าปกติ (→ module ขาย)
  │
  ├─ บันทึกค่าใช้จ่าย:
  │   ├─ กด "บันทึกค่าใช้จ่าย"
  │   ├─ ประเภท: ค่าน้ำ / ค่าไฟ / ค่าแรง / อื่นๆ
  │   ├─ กรอกจำนวนเงิน + หมายเหตุ
  │   └─ บันทึก → หักจากยอดเงินสดในเก๊ะ
  │
  ├─ ส่งเงิน (กรณีเงินล้นเก๊ะ):
  │   ├─ กด "ส่งเงิน"
  │   ├─ เลือกช่องทาง (ฝากคนขับ / โอน / อื่นๆ)
  │   ├─ กรอกจำนวน + แนบหลักฐาน
  │   └─ บันทึก → รอแอดมินยืนยัน
  │
  └─ รับเงินสดเพิ่ม (กรณีเงินไม่พอทอน):
      ├─ แจ้งแอดมิน
      └─ แอดมินเติมเงินในเก๊ะ + บันทึก
```

---

## Flow 3: ปิดกะ

```
[สิ้นสุดกะ] พนักงานกด "ปิดกะ"
  │
  ▼
ขั้นตอนที่ 1: นับเงินสด
  ├─ นับเงินตามชนิด (ธนบัตร + เหรียญ)
  └─ ระบบรวมยอดนับได้

ขั้นตอนที่ 2: เปรียบเทียบยอด
  ├─ ยอดที่ควรมี = เงินตั้งต้น + รับสด - จ่ายสด - ส่งเงิน
  ├─ ยอดที่นับได้ (จากขั้นตอน 1)
  └─ ผลต่าง = ยอดนับได้ - ยอดที่ควรมี
       ├─ [ตรง] → ดำเนินการต่อ
       ├─ [เกิน] → แจ้ง "ยอดเงินเกิน" → บันทึกหมายเหตุ
       └─ [ขาด] → แจ้ง "ยอดเงินขาด" → ระบุสาเหตุ

ขั้นตอนที่ 3: ส่งมอบกะ
  ├─ บันทึกยอดส่งมอบ
  ├─ ยอดนี้กลายเป็นยอดเปิดกะถัดไป
  └─ กด "ยืนยันปิดกะ" → กะปิด
```

---

## Flow 4: รายงานกะ

```
[เจ้าของ/แอดมิน] → "รายงานกะ"
  │
  ▼
เลือกกะที่ต้องการดู
  │
  ▼
แสดง:
  ├─ ยอดขาย (รวม, รายสินค้า)
  ├─ ยอดเงินสด (ตั้งต้น, รับ, จ่าย, ส่ง, ปิดกะ)
  ├─ ยอดโอน
  ├─ ค่าใช้จ่ายระหว่างกะ
  ├─ ผลต่างเงิน (ถ้ามี)
  └─ รายการบิลทั้งหมดในกะ
```

---

## Flow 5: แจ้งยอดเงินไม่ตรง

```
[พนักงาน] พบยอดเงินไม่ตรง → "รายงานยอดเงินไม่ตรง"
  │
  ▼
กรอก:
  ├─ ยอดที่ควรมี
  ├─ ยอดที่นับได้
  ├─ สาเหตุที่คาดว่าเป็น
  └─ หลักฐาน (ถ้ามี)
  │
  ▼
ส่งรายงาน → แอดมินรับแจ้งเตือน → ตรวจสอบ → บันทึกผล
```

---

## Flow 6: Admin Badge Dashboard

```
[แอดมิน/เจ้าของ] → หน้า "ภาพรวมกะ"
  │
  ├─ badge "กะไม่ปิด" — กะที่ยังไม่ปิดและมีกะถัดไปเปิดแล้ว
  │   └─ คลิก → ดูรายละเอียดกะ + พนักงานที่รับผิดชอบ
  │
  └─ badge "ยอดเงินไม่ตรง" — opening_cash (กะใหม่) ≠ closing_cash_counted (กะก่อน)
      └─ คลิก → ดูยอดเงินปิดกะก่อน vs เปิดกะใหม่ + ผลต่าง
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| เงินในเก๊ะบางชนิดไม่พอทอน | แจ้งเตือน "เงินในเก๊ะบางชนิดไม่พอ" |
| พนักงานคนเดียวกันเปิดกะซ้อน | บล็อก "คุณมีกะเปิดอยู่แล้ว" |
| กะก่อน (พนักงานอื่น) ยังไม่ปิด | อนุญาตให้เปิดกะใหม่ได้ + badge "กะไม่ปิด" แจ้งแอดมิน |
| ยอดเงินเปิดกะ ≠ ยอดปิดกะก่อน | badge "ยอดเงินไม่ตรง" แจ้งแอดมิน — พนักงานไม่เห็น |
| ยอดเงินขาดมาก | ส่ง alert พิเศษให้เจ้าของ |
