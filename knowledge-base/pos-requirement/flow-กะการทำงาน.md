# Flow — Module: กะการทำงาน (Shift Management)

## ภาพรวม
Module ควบคุมวงจรกะการทำงาน: เปิดกะ → ขาย → ส่งเงิน → ปิดกะ พร้อมระบบตรวจสอบยอดเงินและรายงานกะ

---

## Flow 1: เปิดกะ

```
พนักงาน Login → ระบบตรวจสอบ
  │
  ├─ [ยังไม่มีกะเปิด] → แสดงหน้า "เปิดกะ"
  │   ├─ แสดงยอดเงินในเก๊ะจากกะก่อน
  │   ├─ นับเงินสดตั้งต้น (กรอกจำนวนต่อชนิด)
  │   ├─ ยืนยันยอดเงินตั้งต้น
  │   └─ กด "ยืนยันเปิดกะ" → กะเปิด → เริ่มขายได้
  │
  └─ [มีกะเปิดอยู่] → เข้าสู่หน้าขายทันที
```

---

## Flow 2: ระหว่างกะ (ขาย + จัดการเงิน)

```
[ระหว่างกะ]
  │
  ├─ ขายสินค้าปกติ (→ module ขาย)
  │
  ├─ บันทึกค่าใช้จ่าย:
  │   ├─ กด "บันทึกค่าใช้จ่าย"
  │   ├─ ประเภท: ค่าน้ำ / ค่าไฟ / ค่าแรง / อื่นๆ
  │   ├─ กรอกจำนวนเงิน + หมายเหตุ
  │   └─ บันทึก → หักจากยอดเงินสดในเก๊ะ
  │
  ├─ ส่งเงิน (กรณีเงินล้นเก๊ะ):
  │   ├─ กด "ส่งเงิน"
  │   ├─ เลือกช่องทาง (ฝากคนขับ / โอน / อื่นๆ)
  │   ├─ กรอกจำนวน + แนบหลักฐาน
  │   └─ บันทึก → รอแอดมินยืนยัน
  │
  └─ รับเงินสดเพิ่ม (กรณีเงินไม่พอทอน):
      ├─ แจ้งแอดมิน
      └─ แอดมินเติมเงินในเก๊ะ + บันทึก
```

---

## Flow 3: ปิดกะ

```
[สิ้นสุดกะ] พนักงานกด "ปิดกะ"
  │
  ▼
ขั้นตอนที่ 1: นับเงินสด
  ├─ นับเงินตามชนิด (ธนบัตร + เหรียญ)
  └─ ระบบรวมยอดนับได้

ขั้นตอนที่ 2: เปรียบเทียบยอด
  ├─ ยอดที่ควรมี = เงินตั้งต้น + รับสด - จ่ายสด - ส่งเงิน
  ├─ ยอดที่นับได้ (จากขั้นตอน 1)
  └─ ผลต่าง = ยอดนับได้ - ยอดที่ควรมี
       ├─ [ตรง] → ดำเนินการต่อ
       ├─ [เกิน] → แจ้ง "ยอดเงินเกิน" → บันทึกหมายเหตุ
       └─ [ขาด] → แจ้ง "ยอดเงินขาด" → ระบุสาเหตุ

ขั้นตอนที่ 3: ส่งมอบกะ
  ├─ บันทึกยอดส่งมอบ
  ├─ ยอดนี้กลายเป็นยอดเปิดกะถัดไป
  └─ กด "ยืนยันปิดกะ" → กะปิด
```

---

## Flow 4: รายงานกะ

```
[เจ้าของ/แอดมิน] → "รายงานกะ"
  │
  ▼
เลือกกะที่ต้องการดู
  │
  ▼
แสดง:
  ├─ ยอดขาย (รวม, รายสินค้า)
  ├─ ยอดเงินสด (ตั้งต้น, รับ, จ่าย, ส่ง, ปิดกะ)
  ├─ ยอดโอน
  ├─ ค่าใช้จ่ายระหว่างกะ
  ├─ ผลต่างเงิน (ถ้ามี)
  └─ รายการบิลทั้งหมดในกะ
```

---

## Flow 5: แจ้งยอดเงินไม่ตรง

```
[พนักงาน] พบยอดเงินไม่ตรง → "รายงานยอดเงินไม่ตรง"
  │
  ▼
กรอก:
  ├─ ยอดที่ควรมี
  ├─ ยอดที่นับได้
  ├─ สาเหตุที่คาดว่าเป็น
  └─ หลักฐาน (ถ้ามี)
  │
  ▼
ส่งรายงาน → แอดมินรับแจ้งเตือน → ตรวจสอบ → บันทึกผล
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| เงินในเก๊ะบางชนิดไม่พอทอน | แจ้งเตือน "เงินในเก๊ะบางชนิดไม่พอ" |
| เปิดกะซ้อนกะเดิม | บล็อก "มีกะเปิดอยู่แล้ว" |
| กะก่อนยังไม่ปิด | ไม่อนุญาตให้พนักงานคนอื่นเปิดกะใหม่ |
| ยอดเงินขาดมาก | ส่ง alert พิเศษให้เจ้าของ |
