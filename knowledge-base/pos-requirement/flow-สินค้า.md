# Flow — Module: สินค้า

## ภาพรวม
Module จัดการข้อมูลสินค้าทั้งหมด ครอบคลุม CRUD สินค้า, จัดการหมวดหมู่, หน่วยขาย, ราคา และสถานะการแสดงผล

---

## Flow 1: เพิ่มสินค้าใหม่

```
ผู้ใช้ (Admin/เจ้าของ)
  │
  ▼
[หน้าสินค้า] → กด "เพิ่มสินค้าใหม่"
  │
  ▼
[ฟอร์มสินค้า]
  ├─ กรอกชื่อสินค้า (บังคับ)
  ├─ กรอกบาร์โค้ด (ไม่บังคับ)
  ├─ เลือกหมวดหมู่หลัก + หมวดย่อย
  ├─ กำหนดหน่วยฐาน
  ├─ กรอกราคาขาย (ต่อหน่วยฐาน)
  ├─ กรอกราคาทุน (ต้นทุน)
  ├─ อัปโหลดรูปสินค้า (ไม่บังคับ)
  ├─ เพิ่มแท็กสินค้า (ไม่บังคับ)
  └─ ระบุวัตถุประสงค์ (ไม่บังคับ)
  │
  ▼
กด "บันทึกสินค้า"
  │
  ├─ [ข้อมูลครบ] → บันทึกสำเร็จ → แจ้ง "บันทึกเรียบร้อย"
  └─ [ข้อมูลไม่ครบ] → แจ้ง "กรุณากรอกข้อมูลให้ครบ"
```

---

## Flow 2: แก้ไขสินค้า

```
[หน้าสินค้า] → ค้นหาสินค้า → กดสินค้าที่ต้องการ
  │
  ▼
[หน้ารายละเอียดสินค้า]
  ├─ กด "แก้ไขสินค้า"
  │   └─ แก้ไขข้อมูลต้องการ → กด "บันทึก"
  │       ├─ สำเร็จ → แจ้ง "แก้ไขเรียบร้อย"
  │       └─ ล้มเหลว → แจ้งข้อผิดพลาด
  │
  ├─ กด "ซ่อนจากหน้าขาย" → สินค้าไม่แสดงในหน้าขายและสต็อก
  │
  ├─ กด "ปิดใช้งาน" → สินค้าถูกปิดถาวร (ต้องเปิดใช้งานเพื่อคืน)
  │
  └─ กด "เปิดใช้งานอีกครั้ง" → คืนสถานะปกติ
```

---

## Flow 3: จัดการหมวดหมู่

```
[การตั้งค่า] → หมวดหมู่สินค้า
  │
  ├─ เพิ่มหมวดหลัก → กรอกชื่อ → บันทึก
  ├─ เพิ่มหมวดย่อย → เลือกหมวดหลัก → กรอกชื่อ → บันทึก
  ├─ แก้ไขหมวดหลัก / หมวดย่อย
  └─ ลบหมวดหลัก (ถ้ามีสินค้าในหมวด → แจ้งเตือน)
```

---

## Flow 4: จัดการหน่วยขาย (หน่วยซ้อน)

```
[หน้าสินค้า] → เลือกสินค้า → "เพิ่มหน่วยขาย"
  │
  ▼
กรอก:
  ├─ ชื่อหน่วย (เช่น แพ็ค, ลัง, กล่อง)
  ├─ อัตราเทียบ (เช่น 1 แพ็ค = 12 ชิ้น)
  ├─ ราคาขายต่อหน่วยนี้
  └─ กำหนดเป็นหน่วยหลักสำหรับขาย (toggle)
  │
  ▼
บันทึก → ระบบคำนวณราคาให้อัตโนมัติ
```

---

## Flow 5: ค้นหาสินค้า

```
[หน้าสินค้า / หน้าขาย]
  │
  ▼
พิมพ์ชื่อสินค้าในช่องค้นหา
  ├─ ค้นหาตามชื่อ
  ├─ ค้นหาตามบาร์โค้ด
  ├─ กรองตามหมวดหมู่
  └─ กรองตามสถานะ (ปกติ / ปิด / ซ่อน)
  │
  ▼
แสดงผลลัพธ์ → เลือกสินค้า
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| บาร์โค้ดซ้ำ | แจ้งเตือน "บาร์โค้ดนี้มีแล้ว" |
| ลบหมวดที่มีสินค้า | บล็อก + แจ้งจำนวนสินค้าที่ใช้หมวดนี้ |
| ราคาขายต่ำกว่าต้นทุน | แจ้งเตือน "ราคาต่ำกว่าต้นทุน" |
| สินค้าถูกปิดแต่ยังมีในออเดอร์ | ไม่สามารถปิดได้จนกว่าออเดอร์จะสำเร็จ |
| อัปโหลดรูปขนาดใหญ่ | compress ก่อนบันทึก |
