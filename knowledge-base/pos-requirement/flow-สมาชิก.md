# Flow — Module: สมาชิก (Member / Loyalty)

## ภาพรวม
Module จัดการสมาชิกร้าน ระบบแต้มสะสม การแลกแต้ม และสิทธิประโยชน์สมาชิก

---

## Flow 1: สมัครสมาชิกใหม่

```
[หน้าขาย หรือ หน้าสมาชิก] → "สมัครสมาชิกใหม่"
  │
  ▼
กรอกข้อมูล:
  ├─ ชื่อ-นามสกุล (บังคับ)
  ├─ เบอร์โทร (บังคับ, unique)
  ├─ วันเกิด (ไม่บังคับ)
  ├─ เลขบัตรประชาชน (ไม่บังคับ)
  └─ หมายเหตุ
  │
  ▼
ตั้งวันที่สมัคร (default = วันนี้)
  │
  ▼
กด "บันทึกสมาชิก"
  ├─ [สำเร็จ] → แจ้ง "สมัครสมาชิกเรียบร้อย"
  └─ [เบอร์ซ้ำ] → แจ้ง "เบอร์โทรนี้มีแล้ว"
```

---

## Flow 2: ค้นหาสมาชิกขณะขาย

```
[หน้าขาย] → ช่องค้นหาสมาชิก
  │
  ▼
พิมพ์เบอร์โทร (ค้นหา real-time)
  │
  ├─ [พบ] → แสดงชื่อ, แต้มสะสม, สิทธิ์
  │   └─ กด "เลือก" → ผูกสมาชิกกับบิล
  │
  └─ [ไม่พบ] → แสดงปุ่ม "สมัครใหม่"
```

---

## Flow 3: สะสมแต้ม

```
[บิลที่ผูกสมาชิก] → ชำระเงินสำเร็จ
  │
  ▼
ระบบคำนวณแต้มอัตโนมัติ:
  ├─ ยอดซื้อ ÷ อัตราสะสม = แต้มที่ได้
  └─ แต้มบวกเข้าบัญชีสมาชิกทันที
  │
  ▼
แสดงแต้มที่ได้รับในบิล
แต้มจะหมดอายุพร้อมกันทุกวันที่ 31 ธันวาคมของทุกปี
```

---

## Flow 4: แลกแต้มเป็นส่วนลด

```
[หน้าขาย] → เลือกสมาชิก → มีแต้มสะสม
  │
  ▼
กด "ใช้แต้ม"
  ├─ แสดงแต้มที่มี
  ├─ แสดงส่วนลดสูงสุดที่แลกได้ (จำกัดต่อบิล)
  └─ กรอกแต้มที่ต้องการแลก
  │
  ▼
ระบบคำนวณส่วนลด → ลดจากยอดบิล
  │
  ▼
ยืนยันชำระ → แต้มถูกหัก → บันทึกประวัติ
```

---

## Flow 5: แก้ไขข้อมูลสมาชิก

```
[หน้าสมาชิก] → ค้นหาสมาชิก → เลือก
  │
  ▼
[หน้ารายละเอียดสมาชิก]
  ├─ แก้ไขข้อมูลส่วนตัว
  ├─ ดูประวัติการซื้อ
  ├─ ดูประวัติแต้ม (ได้รับ/ใช้/หมดอายุ)
  └─ ดูสถิติการซื้อ
```

---

## Flow 6: ตั้งค่าระบบแต้มสะสม

```
[เจ้าของ] → ตั้งค่าแต้มสมาชิก
  │
  ▼
กำหนด:
  ├─ อัตราสะสม: ทุก X บาท = 1 แต้ม
  ├─ อัตราแลก: 1 แต้ม = Y บาท (ส่วนลด)
  ├─ แต้มขั้นต่ำในการแลก
  ├─ จำกัดแต้มที่แลกได้ต่อบิล (%)
  └─ อนุญาตใช้แต้มร่วมกับโปรโมชัน (toggle)
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| ถึง 31 ธ.ค. ของทุกปี | ระบบสร้าง `expire` transaction + รีเซ็ต total_points = 0 ทุกสมาชิก |
| สมาชิกมีแต้ม 0 ในวัน 31 ธ.ค. | ไม่สร้าง transaction (ไม่มีแต้มให้ตัด) |
| ยกเลิกบิลที่ใช้แต้ม | คืนแต้มที่ใช้ + หักแต้มที่ได้รับจากบิลนั้น |
| ยกเลิกบิลที่ได้แต้ม | หักแต้มที่ได้รับจากบิลนั้นคืน |
| เบอร์โทรซ้ำ | บล็อก แจ้ง "เบอร์นี้มีสมาชิกแล้ว" |
