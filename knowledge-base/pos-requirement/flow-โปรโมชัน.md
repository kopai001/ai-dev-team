# Flow — Module: โปรโมชัน (Promotion)

## ภาพรวม
Module จัดการโปรโมชันทุกรูปแบบ ครอบคลุม: ส่วนลดราคา, ชุดสินค้า (bundle), และโปรสมาชิก

---

## Flow 1: สร้างโปรโมชันใหม่

```
[เจ้าของ/แอดมิน] → "สร้างโปรโมชันใหม่"
  │
  ▼
เลือกประเภทโปร:
  ├─ [ส่วนลดราคา] → กำหนด % หรือจำนวนเงิน + เงื่อนไข
  ├─ [โปรชุด] → เลือกสินค้าในชุด + ราคาชุด
  └─ [โปรสมาชิก] → กำหนดเฉพาะกลุ่มสมาชิก
  │
  ▼
กำหนด:
  ├─ ชื่อโปร
  ├─ ช่วงวันที่มีผล (start - end)
  ├─ เงื่อนไข (ซื้อครบ X บาท / X ชิ้น)
  ├─ สาขาที่ใช้ได้
  └─ กลุ่มลูกค้า (ทั่วไป/สมาชิก/ทั้งคู่)
  │
  ▼
กด "สร้างโปรโมชัน" → บันทึก → ระบบใช้อัตโนมัติ
```

---

## Flow 2: สร้างโปรชุด (Bundle)

```
[เจ้าของ/แอดมิน] → "ทำโปรชุด"
  │
  ▼
กด "สร้างโปรชุดจาก" → เลือกสินค้า
  │
  ▼
เพิ่มสินค้าในชุด:
  ├─ ค้นหาสินค้า
  └─ กำหนดจำนวนต่อสินค้า
  │
  ▼
กำหนดราคาชุด (ต้องน้อยกว่าผลรวมแต่ละชิ้น)
  │
  ▼
ตั้งชื่อชุด + ช่วงวันที่ → บันทึก
```

---

## Flow 3: ระบบแนะนำโปรอัตโนมัติ

```
[หน้าขาย] ลูกค้าเลือกสินค้า
  │
  ▼
ระบบตรวจสอบโปรที่ match อัตโนมัติ:
  ├─ โปรส่วนลด (ถ้ายอดถึงเกณฑ์)
  ├─ โปรชุด (ถ้าซื้อสินค้าในชุดครบ)
  └─ โปรสมาชิก (ถ้าเลือกสมาชิก)
  │
  ▼
แสดงโปรที่ match บน UI → ใช้อัตโนมัติ หรือยืนยัน
  └─ ระบบแนะนำโปรที่คุ้มที่สุดให้ลูกค้าอัตโนมัติ
```

---

## Flow 4: ดูและจัดการโปรโมชัน

```
[หน้าโปรโมชัน]
  │
  ├─ ดูโปรโมชันทั้งหมด (active/inactive/expired)
  ├─ เปิด/ปิดโปรโมชัน
  ├─ แก้ไขโปรโมชัน (ที่ยังไม่มีการใช้งาน)
  └─ ดูสถิติการใช้โปรโมชัน
```

---

## Flow 5: วิเคราะห์ตะกร้าสินค้า (Market Basket Analysis)

```
[เจ้าของ] → หน้ารายงาน → "วิเคราะห์ตะกร้าสินค้า"
  │
  ▼
ระบบวิเคราะห์สินค้าที่ซื้อพร้อมกันบ่อย
  │
  ▼
แสดง: คู่สินค้าที่นิยมซื้อด้วยกัน + % ความถี่
  │
  ▼
"เพิ่มทั้งหมดที่แนะนำ" → สร้างโปรชุดจากข้อมูลนี้
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| โปรหลายอันใช้พร้อมกันได้? | ตามที่ตั้งค่า (กำหนดได้ว่า stack หรือไม่) |
| โปรหมดอายุระหว่างขาย | ใช้โปรที่ active ณ เวลาบันทึกบิล |
| ยกเลิกบิลที่ใช้โปร | ยกเลิกส่วนลดโปรโมชันด้วย |
| โปรชุดสินค้าบางรายการหมด | แจ้งเตือนในหน้าขาย ยังใช้โปรได้ถ้าสต็อกพอ |
