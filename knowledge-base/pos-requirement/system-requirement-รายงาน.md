# System Requirement — Module: รายงาน (Reports)

## FR-RPT-001: รายงานยอดขาย
- แสดงยอดขายรายวัน/สัปดาห์/เดือน
- เลือกดูรวมทุกสาขาหรือแยกสาขา
- แสดง: ยอดขาย, จำนวนบิล, บิลเฉลี่ย, ส่วนลด, ยอดสุทธิ
- แยกยอดตามช่องทางชำระ (เงินสด/โอน/พร้อมเพย์)
- กราฟแสดงแนวโน้มยอดขาย

## FR-RPT-002: รายงานกำไร
- คำนวณกำไรขั้นต้น (ยอดขาย - ต้นทุน)
- คำนวณกำไรสุทธิ (ขั้นต้น - ค่าใช้จ่ายกะ)
- แสดงอัตรากำไรเป็น %
- เปรียบเทียบกำไรระหว่างสาขา

## FR-RPT-003: รายงานสต็อก
- ภาพรวมสต็อกสุขภาพ (% ปกติ/ต่ำ/หมด)
- ตารางสต็อกเปรียบเทียบทุกสาขา
- รายการสินค้าขายดี (Top N)
- รายการสินค้าขายช้า
- รายการใกล้หมดอายุ

## FR-RPT-004: รายงานกะ
- ดูรายงานกะทุกกะย้อนหลัง
- แสดงยอดเงินทุกรายการในกะ
- ไฮไลต์กะที่มีผลต่างเงิน
- รายงานยอดเงินไม่ตรงสะสม

## FR-RPT-005: รายงานสมาชิก
- สมาชิกใหม่ต่อเดือน
- Top สมาชิกตามยอดซื้อ
- สถิติการใช้แต้ม
- วิเคราะห์ตะกร้าสินค้า (Market Basket)

## FR-RPT-006: Export รายงาน
- Export ได้ทุกรายงานเป็น PDF และ Excel/CSV
- รายงานขนาดใหญ่ทำใน background + notify เมื่อเสร็จ

---

## Non-Functional Requirements

### Performance
- รายงานรายวัน/สัปดาห์: โหลดภายใน 3 วินาที
- รายงานรายเดือน/ย้อนหลัง: ใช้ background job ถ้าเกิน 5 วินาที

### Caching
- cache รายงานที่ query แล้ว (TTL: 10 นาที)
- invalidate cache เมื่อมี new order หรือ shift close
