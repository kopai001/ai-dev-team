# System Requirement — Module: สินค้า

## FR-PRD-001: เพิ่มสินค้าใหม่
- ระบบต้องรองรับการเพิ่มสินค้าใหม่ด้วยข้อมูล: ชื่อ, หมวดหมู่, หน่วยฐาน, ราคาขาย, ราคาทุน
- บาร์โค้ดต้องไม่ซ้ำในระบบ (unique constraint)
- รองรับการอัปโหลดรูปสินค้า (JPG/PNG/WEBP, ขนาดไม่เกิน 5MB)
- ระบบ compress รูปก่อนบันทึกให้อัตโนมัติ
- ระบุ `has_expiry_date` (true/false) เมื่อสร้างสินค้า — ควบคุมว่าสินค้านี้ต้องกรอก expiry_date ตอนรับและติดตาม lot expiry หรือไม่

## FR-PRD-002: แก้ไขสินค้า
- ระบบต้องรองรับการแก้ไขข้อมูลสินค้าทุกฟิลด์ได้
- บันทึก `updated_at` และ `updated_by` ทุกครั้งที่แก้ไข
- ประวัติการแก้ไขต้องสืบค้นได้ (audit log)
- การแก้ไขข้อมูลสินค้า (ราคา, ชื่อ, หน่วย ฯลฯ) **ไม่ส่งผลต่อบิลที่สำเร็จแล้ว** — บิลบันทึก snapshot ของข้อมูลสินค้า ณ เวลาขายไว้แยกต่างหาก

## FR-PRD-003: จัดการสถานะสินค้า
- ระบบต้องรองรับ 3 สถานะ: active / hidden / disabled
- สินค้า `hidden` ซ่อนจากหน้าขายและหน้าสต็อก แต่ข้อมูลยังอยู่
- สินค้า `disabled` ต้องเปิดใช้งานด้วย action "เปิดใช้งานอีกครั้ง" เท่านั้น
- แจ้งเตือนก่อนปิดถ้าสินค้ายังมีในออเดอร์ที่ยังไม่สำเร็จ

## FR-PRD-004: จัดการหมวดหมู่
- รองรับ 2 ระดับ: หมวดหลัก → หมวดย่อย
- ชื่อหมวดห้ามซ้ำในระดับเดียวกัน
- ลบหมวดหลักได้เฉพาะเมื่อไม่มีหมวดย่อยและสินค้า
- ลบหมวดย่อยได้เฉพาะเมื่อไม่มีสินค้า

## FR-PRD-005: จัดการหน่วยขาย
- รองรับหน่วยซ้อนหลายระดับ (เช่น ชิ้น → แพ็ค → ลัง)
- ระบบคำนวณราคาต่อหน่วยซ้อนอัตโนมัติจาก ratio
- สต็อกถูกตัดในหน่วยฐานเสมอ ไม่ว่าขายหน่วยใด
- สามารถตรึงหน่วยที่ใช้บ่อยในหน้าขายได้

## FR-PRD-006: ค้นหาและกรองสินค้า
- ค้นหาตาม: ชื่อ, บาร์โค้ด, แท็ก
- กรองตาม: หมวดหมู่, สถานะ, สาขา
- รองรับการเรียงลำดับตาม: ชื่อ, ราคา, ยอดขาย, วันที่สร้าง
- แสดงผลลัพธ์ real-time ขณะพิมพ์

## FR-PRD-007: ติดหมุด (Pin) สินค้า
- สามารถตรึงสินค้าในรายการโปรดได้
- สินค้าติดหมุดแสดงก่อนสินค้าอื่นในหน้าขาย

## Non-Functional Requirements

### Performance
- ค้นหาสินค้าตอบสนองภายใน 300ms
- รองรับสินค้าในระบบได้ไม่น้อยกว่า 10,000 รายการ

### Permission
| Action | เจ้าของ | แอดมิน | พนักงาน |
|--------|---------|--------|---------|
| ดูสินค้า | ✓ | ✓ | ✓ |
| เพิ่ม/แก้ไข | ✓ | ✓ | ✗ |
| ลบ/ปิดสินค้า | ✓ | ✓ | ✗ |
| แก้ไขราคา | ✓ | ✓ | ✗ |
| จัดการหมวดหมู่ | ✓ | ✓ | ✗ |

### Data Validation
- ชื่อสินค้า: ไม่เกิน 200 ตัวอักษร, ต้องไม่ว่าง
- ราคา: ≥ 0, ทศนิยมไม่เกิน 2 ตำแหน่ง
- Ratio หน่วย: > 0, ทศนิยมไม่เกิน 4 ตำแหน่ง
- บาร์โค้ด: ตัวเลขหรืออักขระ ≤ 50 ตัว

### UI Requirements
- รูปสินค้าแสดง aspect ratio 1:1 (square)
- แจ้งเตือนราคาต่ำกว่าทุนด้วยสีแดง (ไม่บล็อก)
- หน้าสินค้าแสดง grid view และ list view
- รองรับ offline draft (บันทึกร่างก่อน sync)
