# Flow — Module: สาขา (Branch)

## ภาพรวม
Module จัดการ Branch (สาขาปกติ และ คลังกลาง — ทั้งคู่เป็น stock location เท่ากัน; **1 Branch = 1 สต็อก** โดยคลังกลางเป็น Branch ที่ไม่ผูกกับสาขาปกติ) ครอบคลุมการเพิ่ม, ตั้งค่า, จัดการสิทธิ์

---

## Flow 1: เพิ่มสาขาใหม่

```
[เจ้าของ] → "เปิดฟอร์มเพิ่มสาขาใหม่"
  │
  ▼
กรอกข้อมูล:
  ├─ ชื่อสาขา (บังคับ)
  ├─ ที่อยู่ / โลเคชั่น
  ├─ เบอร์ติดต่อ
  └─ ประเภท (type): สาขาปกติ (branch) / คลังกลาง (warehouse)
      — ทั้งสองประเภทจะมี stock location ของตัวเอง 1 อัน (ใช้กลไก StockBalance/StockLot เดียวกัน)
      — คลังกลางจะไม่รับออเดอร์ขาย/ไม่เปิดกะ ใช้แค่เก็บสต็อกและโอนไปสาขา
  │
  ▼
กด "เพิ่มสาขา" → บันทึก → ตั้งค่าสาขาต่อได้
```

---

## Flow 2: ตั้งค่าสาขา

```
[เจ้าของ/แอดมิน] → เลือกสาขา → "ตั้งค่าสาขา"
  │
  ▼
ตั้งค่า:
  ├─ ข้อมูลพื้นฐาน (ชื่อ, ที่อยู่)
  ├─ เวลาเปิด-ปิด
  ├─ ขั้นต่ำสต็อกสำหรับสาขานี้
  ├─ ตั้งค่าแต้มสมาชิกต่อสาขา (override global)
  └─ พนักงานที่รับผิดชอบ
```

---

## Flow 3: ปิดสาขา

```
[เจ้าของ] → เลือกสาขา → "ปิดทำการ" / "ปิดถาวร"
  │
  ├─ ปิดทำการ (ชั่วคราว): สาขาไม่รับออเดอร์ แต่ข้อมูลยังอยู่
  └─ ปิดถาวร: soft delete ข้อมูลยังอยู่ในรายงานย้อนหลัง
```

---

## Flow 4: จัดการโซน (Zone)

```
[เจ้าของ] → เลือกสาขา → "จัดการโซน"
  │
  ▼
เพิ่ม/แก้ไข/ลบโซนในสาขา
(ใช้สำหรับแบ่งพื้นที่ขายหรือพื้นที่เก็บสินค้า)
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| ปิดสาขาที่มีกะเปิดอยู่ | บล็อก ต้องปิดกะก่อน |
| ลบ Branch ที่มีสต็อก (สาขา หรือ คลังกลาง) | บล็อก ต้องโยกย้ายสต็อกออกไป Branch อื่นก่อน |
| เปลี่ยนชื่อสาขา | อัปเดตทุกที่ที่ใช้ชื่อสาขา |
