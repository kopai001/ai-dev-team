# Flow — Module: สต็อก

## ภาพรวม
Module ติดตามปริมาณสินค้าคงเหลือ ครอบคลุมการดูสต็อก, รับสินค้าเข้า, แจ้งเตือนสต็อกต่ำ, ตรวจสอบวันหมดอายุ และประวัติความเคลื่อนไหว

---

## Flow 1: ดูสต็อกสินค้า

```
[หน้าสต็อก]
  │
  ▼
เลือกมุมมอง:
  ├─ ทุกสาขา (รวม)
  ├─ รายสาขา
  └─ คลังกลาง
  │
  ▼
กรองสต็อก:
  ├─ ตามหมวดหมู่
  ├─ ตามสถานะ (ปกติ / ต่ำ / หมด / ใกล้หมดอายุ)
  └─ แสดงเฉพาะที่ต้องเติม
  │
  ▼
แสดงตาราง:
  ├─ ชื่อสินค้า
  ├─ จำนวนคงเหลือ (ต่อหน่วยฐาน)
  ├─ ขั้นต่ำที่กำหนด
  ├─ วันหมดอายุ (ถ้ามี)
  └─ สถานะสต็อก
```

---

## Flow 2: รับสินค้าเข้าสต็อก

```
[หน้ารับของ] → "เริ่มรับของ"
  │
  ▼
เลือกผู้ขาย / คลังกลาง
  │
  ▼
เพิ่มรายการสินค้า:
  ├─ ค้นหาสินค้า
  ├─ กรอกจำนวนรับ
  ├─ กรอกจำนวนจริงที่ได้รับ (อาจต่างกัน)
  ├─ กรอกราคาทุน (ถ้าต่างจากปกติ)
  └─ ระบุวันหมดอายุ (ถ้ามี)
  │
  ▼
ตรวจสอบรายการ → กด "บันทึกรับของ"
  │
  ├─ [จำนวนรับครบ] → บันทึก → สต็อกเพิ่ม
  ├─ [รับไม่ครบ] → บันทึกพร้อมหมายเหตุ "รับขาด X ชิ้น"
  └─ [รับเกิน] → บันทึกพร้อมหมายเหตุ "รับเกิน X ชิ้น"
```

---

## Flow 3: แจ้งเตือนสต็อกต่ำ

```
ระบบตรวจสอบสต็อกอัตโนมัติทุกวัน
  │
  ▼
สต็อก ≤ ขั้นต่ำที่กำหนด
  │
  ▼
แจ้งเตือน:
  ├─ แสดง badge "สต็อกต่ำ" บนสินค้า
  ├─ แสดงรายการในหน้า "สต็อกต่ำ"
  └─ แจ้งเตือนผู้มีสิทธิ์ (แอดมิน/เจ้าของ)
  │
  ▼
ผู้ใช้กด "สั่งเติม" → สร้างรายการโยกย้ายหรือแจ้งผู้ขาย
```

---

## Flow 4: แจ้งเตือนวันหมดอายุ

```
ระบบตรวจวันหมดอายุทุกวัน
  │
  ▼
สินค้าหมดอายุภายใน X วัน (ตามที่กำหนด)
  │
  ▼
แสดงใน:
  ├─ รายการ "ใกล้หมดอายุ"
  ├─ แจ้งเตือนในหน้าสต็อก
  └─ รายงาน (สำหรับเจ้าของ)
```

---

## Flow 5: ตัดสต็อก (Manual Adjustment)

```
[หน้าสต็อก] → เลือกสินค้า → "ขอตัดสต็อก"
  │
  ▼
กรอก:
  ├─ จำนวนที่ต้องการตัด
  └─ สาเหตุ (สูญหาย / เสียหาย / หมดอายุ / อื่นๆ)
  │
  ▼
ส่งคำขอตัดสต็อก → รอแอดมินหลักอนุมัติ
  │
  ├─ [อนุมัติ] → สต็อกถูกตัด → บันทึกประวัติ
  └─ [ปฏิเสธ] → แจ้งพนักงาน + บันทึกเหตุผล
```

---

## Flow 6: ดูประวัติสต็อก

```
[หน้าสต็อก] → เลือกสินค้า → "ประวัติสต็อก"
  │
  ▼
แสดงความเคลื่อนไหว:
  ├─ รับเข้า (วันที่, จำนวน, ผู้ขาย)
  ├─ ขายออก (วันที่, จำนวน, บิลที่อ้างอิง)
  ├─ โยกย้าย (วันที่, จาก-ถึง, จำนวน)
  └─ ตัดสต็อก (วันที่, จำนวน, เหตุผล, ผู้อนุมัติ)
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| รับสินค้าเกินจำนวนสั่ง | บันทึกได้ แต่แจ้งเตือน "รับเกิน" |
| ตัดสต็อกทำให้ติดลบ | บล็อก แจ้ง "สต็อกไม่เพียงพอ" |
| สินค้าหมดอายุแล้ว | แสดง badge แดง, ไม่บล็อกการขาย |
| สต็อกไม่ตรงกับที่นับจริง | บันทึก "ผลต่าง" + เหตุผล |
