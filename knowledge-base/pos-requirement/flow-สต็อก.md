# Flow — Module: สต็อก

## ภาพรวม
Module ติดตามปริมาณสินค้าคงเหลือ ครอบคลุมการดูสต็อก, รับสินค้าเข้า (พร้อมสร้าง StockLot), แจ้งเตือนสต็อกต่ำ/หมดอายุ, นับสต็อก, ตรวจสอบวันหมดอายุ และประวัติความเคลื่อนไหว

---

## Flow 1: ดูสต็อกสินค้า

```
[หน้าสต็อก]
  │
  ▼
เลือกมุมมอง (แต่ละ Branch = 1 stock location):
  ├─ ทุก Branch (รวมสาขา+คลังกลาง)
  ├─ ราย Branch — เลือกจาก dropdown Branch ทั้งหมด (สาขา หรือ คลังกลาง)
  └─ กรองด้วย type (สาขาปกติ / คลังกลาง) ได้
  │
  ▼
กรองสต็อก:
  ├─ ตามหมวดหมู่
  ├─ ตามสถานะ (ปกติ / ต่ำ / หมด / ใกล้หมดอายุ / หมดอายุแล้ว)
  └─ แสดงเฉพาะที่ต้องเติม
  │
  ▼
แสดงตาราง:
  ├─ ชื่อสินค้า
  ├─ จำนวนคงเหลือ (ต่อหน่วยฐาน)
  ├─ ขั้นต่ำที่กำหนด
  ├─ สถานะสต็อก
  └─ [ขยาย] แสดงรายการล็อต: lot_no, expiry_date, qty ต่อล็อต
```

---

## Flow 2: รับสินค้าเข้าสต็อก (สร้าง StockLot อัตโนมัติ)

```
[หน้ารับของ] → "เริ่มรับของ"
  │
  ▼
เลือก Branch ปลายทาง (สาขาปกติ หรือ คลังกลาง — Branch record ใดก็ได้ที่มีสิทธิ์)
  │
  ▼
เลือกผู้ขาย (ถ้ารับจากภายนอก) หรือเว้นว่าง (ถ้ารับจากภายในระบบ)
  │
  ▼
เพิ่มรายการสินค้า:
  ├─ ค้นหาสินค้า
  ├─ กรอกจำนวนรับ
  ├─ กรอกจำนวนจริงที่ได้รับ (อาจต่างกัน)
  ├─ กรอกราคาทุน (ถ้าต่างจากปกติ)
  └─ ระบุวันหมดอายุ (ถ้ามี) — ใช้สร้าง StockLot
  │
  ▼
ตรวจสอบรายการ → กด "บันทึกรับของ"
  │
  ▼
ระบบสร้าง StockLot อัตโนมัติ:
  ├─ 1 StockLot ต่อ 1 (สินค้า + วันหมดอายุ) ในใบรับนี้
  ├─ StockLotBalance สร้างที่ Branch ที่รับ (branch_id ชี้ไป Branch นั้น — สาขา หรือ คลังกลาง)
  ├─ StockBalance เพิ่ม (รวม)
  └─ StockMovement type=receive บันทึก (ระบุ lot_id)
  │
  ├─ [จำนวนรับครบ] → บันทึก → สต็อกเพิ่ม
  ├─ [รับไม่ครบ] → บันทึกพร้อมหมายเหตุ "รับขาด X ชิ้น"
  └─ [รับเกิน] → บันทึกพร้อมหมายเหตุ "รับเกิน X ชิ้น"
```

---

## Flow 3: แจ้งเตือนสต็อกต่ำ

```
ระบบตรวจสอบสต็อกอัตโนมัติทุกวัน
  │
  ▼
สต็อก ≤ ขั้นต่ำที่กำหนด
  │
  ▼
แจ้งเตือน:
  ├─ แสดง badge "สต็อกต่ำ" บนสินค้า
  ├─ แสดงรายการในหน้า "สต็อกต่ำ"
  └─ แจ้งเตือนผู้มีสิทธิ์ (แอดมิน/เจ้าของ)
  │
  ▼
ผู้ใช้กด "สั่งเติม" → สร้างรายการโยกย้ายหรือแจ้งผู้ขาย
```

---

## Flow 4: แจ้งเตือนวันหมดอายุ (Auto-Expire)

```
Background job รันทุกวันเที่ยงคืน
  │
  ▼
ตรวจ StockLot: expiry_date < today AND status = active
  │
  ▼
เปลี่ยน StockLot.status → expired อัตโนมัติ
  │
  ▼
แจ้งเตือนแอดมิน/เจ้าของ:
  ├─ รายชื่อสินค้าที่หมดอายุวันนี้ (พร้อม lot_no, จำนวน, สาขา)
  └─ แสดงใน dashboard "สต็อกหมดอายุ"

---[แยก]---

ระบบตรวจล็อตใกล้หมดอายุ:
  ├─ expiry_date - today ≤ X วัน (ตามที่ตั้งค่า, default 7 วัน)
  └─ แสดงในรายการ "ใกล้หมดอายุ" แยกต่างหาก
```

---

## Flow 5: ตัดสต็อก (Manual Adjustment)

```
[หน้าสต็อก] → เลือกสินค้า → "ขอตัดสต็อก"
  │
  ▼
กรอก:
  ├─ จำนวนที่ต้องการตัด
  ├─ สาเหตุ (สูญหาย / เสียหาย / หมดอายุ / อื่นๆ)
  └─ เลือกล็อต (ไม่บังคับ — ถ้าไม่เลือก ระบบใช้ FEFO)
  │
  ▼
ส่งคำขอตัดสต็อก → รอแอดมินอนุมัติ
  │
  ├─ [อนุมัติ] → ตัดจาก StockLotBalance (FEFO หรือตามที่ระบุ)
  │              → StockBalance ลด → StockMovement บันทึก
  └─ [ปฏิเสธ] → แจ้งพนักงาน + บันทึกเหตุผล
```

---

## Flow 6: ดูประวัติสต็อก

```
[หน้าสต็อก] → เลือกสินค้า → "ประวัติสต็อก"
  │
  ▼
แสดงความเคลื่อนไหว (StockMovement):
  ├─ รับเข้า (วันที่, จำนวน, ผู้ขาย, lot_no)
  ├─ ขายออก (วันที่, จำนวน, บิลที่อ้างอิง, lot_no)
  ├─ โยกย้าย (วันที่, จาก-ถึง, จำนวน, lot_no)
  └─ ตัดสต็อก (วันที่, จำนวน, เหตุผล, ผู้อนุมัติ, lot_no)
  │
  ▼
กรองได้ตาม: ประเภท, ช่วงวันที่, สาขา, lot_no
```

## Flow 7: นับสต็อก (Stock Count)

```
[หน้าสต็อก] → "เริ่มนับสต็อก"
  │
  ▼
เลือก Branch ที่ต้องการนับ (สาขาปกติ หรือ คลังกลาง — เจ้าของ/แอดมินเลือกได้ทุก Branch)
  │
  ▼
เลือกสินค้าที่จะนับ:
  ├─ เลือกทีละรายการ หรือ เลือกตามหมวดหมู่
  └─ ไม่จำเป็นต้องนับทุกสินค้า — นับเฉพาะที่เลือกเท่านั้น
  │
  ▼
ระบบสร้าง StockCount (status=draft):
  ├─ โหลดเฉพาะสินค้าที่เลือก
  └─ Snapshot ยอด system_qty (รวมทุกล็อต) ณ เวลานี้
  │
  ▼
เปลี่ยนสถานะเป็น "กำลังนับ" (status=in_progress)
  │
  ▼
พนักงานนับสินค้าจริง:
  ├─ กรอก counted_qty รวม ต่อสินค้า (ไม่แยกล็อต)
  └─ บันทึกหมายเหตุต่อรายการที่ผิดปกติ
  │
  ▼
กด "ยืนยันผลการนับ" (status=completed)
  │
  ▼
ระบบคำนวณ difference = counted_qty - system_qty ต่อสินค้า
  │
  ├─ [ไม่มีผลต่าง] → บันทึกเรียบร้อย ไม่มีการปรับยอด
  └─ [มีผลต่าง] → สร้าง StockAdjustment (reason_type=count_variance) → รอแอดมินอนุมัติ
  │
  ▼
แอดมินอนุมัติการปรับยอด (ต่อสินค้าแต่ละรายการ):
  │
  ├─ [อนุมัติ]
  │   ├─ ตัด StockLotBalance ล็อตเก่าทั้งหมดใน Branch เป็น 0
  │   │   (StockMovement type=count_adjustment ลบยอดทุกล็อต)
  │   ├─ สร้าง StockLot ใหม่ 1 lot:
  │   │   qty = counted_qty, received_date = today, ไม่มี expiry_date
  │   ├─ สร้าง StockLotBalance ของ lot ใหม่ใน Branch = counted_qty
  │   ├─ อัปเดต StockBalance = counted_qty
  │   └─ StockMovement type=count_adjustment บันทึกสุทธิ
  │
  └─ [ปฏิเสธ] → ยอดสต็อกไม่เปลี่ยน + บันทึกเหตุผล
```

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| รับสินค้าเกินจำนวนสั่ง | บันทึกได้ แต่แจ้งเตือน "รับเกิน" |
| ตัดสต็อกทำให้ติดลบ | บล็อก แจ้ง "สต็อกไม่เพียงพอ" |
| สินค้าหมดอายุแล้ว (lot.status=expired) | แสดง badge แดง ไม่บล็อกการขาย แต่แจ้งเตือน |
| นับสต็อกซ้อนกับธุรกรรมปกติ | ระบบไม่ lock — difference คำนวณจาก snapshot ณ เวลาเริ่มนับ |
| นับสินค้าไม่ครบทุกรายการ | สินค้าที่ไม่ได้เลือกนับไม่มีผลต่อสต็อก |
| สินค้ามี has_expiry_date=false | ไม่มี expiry_date — ตัด lot ตาม FIFO (received_date เก่าสุด) |
| ล็อตเดียวกระจายหลาย Branch | แสดง StockLotBalance แยกต่อ Branch (รวมคลังกลาง) |
| ต้องการตัดล็อตเฉพาะ | ระบุ stock_lot_id ใน Adjustment เพื่อ override FEFO |
| สต็อกไม่ตรงกับที่นับจริง | ใช้ Flow 7 (นับสต็อก) → สร้าง Adjustment ผ่านการอนุมัติ |
