# System Requirement — Module: สมาชิก (Member / Loyalty)

## FR-MBR-001: สมัครสมาชิก
- สมัครสมาชิกได้จากหน้าขายหรือหน้าจัดการสมาชิก
- เบอร์โทรต้องไม่ซ้ำในระบบ (unique)
- บันทึกสาขาที่สมัครและพนักงานที่รับสมัคร
- ค้นหาสมาชิกด้วยเบอร์โทรได้ real-time

## FR-MBR-002: สะสมแต้ม
- แต้มสะสมอัตโนมัติทุกครั้งที่ชำระบิลที่ผูกสมาชิก
- คำนวณแต้ม: floor(ยอดบิลสุทธิ / earn_rate)
- แสดงแต้มที่ได้รับในบิล
- บันทึกวันหมดอายุต่อ batch แต้ม

## FR-MBR-003: แลกแต้ม
- แสดงแต้มสะสม + ส่วนลดสูงสุดที่แลกได้เมื่อเลือกสมาชิก
- จำกัดการแลกตาม: แต้มขั้นต่ำ, % ของยอดบิล
- ส่วนลดจากแต้มแสดงแยกจากส่วนลดโปรโมชัน

## FR-MBR-004: วันหมดอายุแต้ม
- แต้มของสมาชิกทุกคนหมดอายุพร้อมกันทุกวันที่ 31 ธันวาคมของทุกปี
- ระบบรีเซ็ตแต้มสมาชิกทุกคนเป็น 0 อัตโนมัติเมื่อสิ้นวัน 31 ธันวาคม
- ไม่มีการแจ้งเตือนล่วงหน้า
- บันทึก PointTransaction ประเภท `expire` สำหรับสมาชิกที่มีแต้มเหลือ > 0 เพื่อเก็บประวัติ

## FR-MBR-005: แก้ไขและดูประวัติ
- แก้ไขข้อมูลส่วนตัวสมาชิกได้
- ดูประวัติการซื้อทั้งหมด
- ดูประวัติแต้ม (ได้รับ/ใช้/หมดอายุ/ปรับ)
- ดูสถิติการซื้อ (ยอดรวม, จำนวนครั้ง, สินค้าที่ซื้อบ่อย)

## FR-MBR-006: ตั้งค่าระบบแต้ม (เจ้าของ)
- ตั้งค่าอัตราสะสม, อัตราแลก, ขั้นต่ำ, จำกัดต่อบิล
- toggle อนุญาตใช้แต้มพร้อมโปรโมชัน
- บันทึกประวัติการเปลี่ยนแปลง config

## FR-MBR-007: ปรับแต้มด้วยมือ (Manual Adjustment)
- แอดมิน/เจ้าของปรับแต้มได้ (บวก/ลบ) พร้อมระบุเหตุผล
- บันทึกประวัติ manual adjustment ทุกครั้ง

## Non-Functional Requirements

### Performance
- ค้นหาสมาชิกด้วยเบอร์โทรภายใน 200ms
- รองรับสมาชิกได้ไม่น้อยกว่า 100,000 ราย
