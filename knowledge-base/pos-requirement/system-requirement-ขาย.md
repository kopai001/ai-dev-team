# System Requirement — Module: ขาย / บิล

## FR-SALE-001: สร้างออเดอร์
- ระบบต้องรองรับการเพิ่มสินค้าเข้าออเดอร์ด้วยวิธี: กดรายการ, ค้นหาชื่อ, สแกนบาร์โค้ด
- ปรับจำนวนสินค้าในออเดอร์ได้ด้วย +/- หรือกรอกตัวเลขโดยตรง
- เปลี่ยนหน่วยขายได้ (เช่น จากชิ้นเป็นแพ็ค) โดยไม่ต้องลบและเพิ่มใหม่
- ลบรายการสินค้าออกจากออเดอร์ได้
- ลบทุกรายการในออเดอร์ได้พร้อมกัน (ต้องยืนยัน)
- รายการในตะกร้าจะถูกลบทั้งหมดเมื่อยืนยัน

## FR-SALE-002: คำนวณยอด
- ระบบต้องคำนวณยอดรวมอัตโนมัติเมื่อมีการเปลี่ยนแปลงออเดอร์
- แสดง: ราคาปกติรวม, ส่วนลด, ยอดสุทธิ, ยอดทอน
- คำนวณส่วนลดโปรโมชันอัตโนมัติตามเงื่อนไข
- แสดงส่วนลดแต้มสมาชิก (ถ้าเลือกสมาชิกและมีแต้ม)

## FR-SALE-003: เลือกลูกค้า
- เลือกได้ระหว่าง "ลูกค้าทั่วไป" หรือค้นหาสมาชิกด้วยเบอร์โทร
- เมื่อเลือกสมาชิก: แสดงแต้มสะสม, ราคาพิเศษ, สิทธิ์โปรโมชัน
- ยกเลิกการเลือกสมาชิกได้ตลอด (กลับเป็นลูกค้าทั่วไป)

## FR-SALE-004: รับชำระเงิน
- รองรับ 3 วิธี: เงินสด, โอนเงิน, พร้อมเพย์
- รองรับการชำระผสม (เช่น เงินสด + โอน) ใน 1 บิล
- เงินสด: ระบบคำนวณเงินทอนอัตโนมัติ
- โอน: รับยอดที่ไม่ตรงพอดีได้ (บันทึกส่วนต่าง)
- แสดงปุ่มเงินสดที่ใช้บ่อย (เช่น 20, 50, 100, 500, 1000)

## FR-SALE-005: ออกบิล
- บันทึกบิลพร้อมสต็อกถูกตัดทันทีเมื่อยืนยันชำระ
- สร้างเลขบิลอัตโนมัติ (unique ต่อสาขา)
- แสดง/พิมพ์ใบเสร็จรับเงิน
- บิลต้องผูกกับกะที่กำลังเปิดอยู่
- ตัดสต็อกตาม FEFO (lot expiry_date ใกล้สุดก่อน) ต่อสินค้าแต่ละรายการอัตโนมัติ
- บันทึก stock_lot_id ใน OrderItem เพื่อ traceability lot

## FR-SALE-006: บิลค้างชำระ
- บันทึกบิลค้างชำระพร้อมระบุลูกค้า (บังคับ)
- แสดงรายการบิลค้างชำระของลูกค้าได้
- รับชำระบิลค้างชำระได้ในภายหลัง
- สต็อกถูกตัดทันทีที่บันทึกค้างชำระ

## FR-SALE-007: ยกเลิกบิล
- ยกเลิกบิลได้เฉพาะผู้มีสิทธิ์ (แอดมิน/เจ้าของ)
- ต้องระบุเหตุผลการยกเลิก
- สต็อกถูกคืนทันทีเมื่อยกเลิก
- แต้มสมาชิกที่ได้รับจากบิลนี้ถูกหักคืน

## FR-SALE-008: ประวัติบิล
- ค้นหาบิลด้วย: เลขบิล, วันที่, พนักงาน, สถานะ, ลูกค้า
- ดูรายละเอียดบิลย้อนหลังได้
- พิมพ์บิลซ้ำได้
- Export รายงานบิลเป็นไฟล์ได้ (เจ้าของ/แอดมิน)

## Non-Functional Requirements

### Performance
- เพิ่มสินค้าเข้าออเดอร์ตอบสนองภายใน 100ms
- บันทึกบิลสำเร็จภายใน 2 วินาที
- รองรับการสแกนบาร์โค้ดต่อเนื่อง (ไม่มี delay)

### Offline Support
- ออเดอร์ที่อยู่ระหว่างสร้างต้อง persist ใน local storage
- บันทึกบิลแบบ offline queue (sync เมื่อออนไลน์)
- สต็อก local cache อัปเดตทุก 5 นาที

### Permission
| Action | เจ้าของ | แอดมิน | พนักงาน |
|--------|---------|--------|---------|
| สร้างบิล | ✓ | ✓ | ✓ |
| ยกเลิกบิล | ✓ | ✓ | ✗ |
| ดูประวัติบิลทั้งหมด | ✓ | ✓ | เฉพาะตัวเอง |
| บิลค้างชำระ | ✓ | ✓ | ✓ |
| Export บิล | ✓ | ✓ | ✗ |

### UI Requirements
- หน้าขายต้องใช้งานได้บน tablet (landscape mode)
- ปุ่มสินค้าขนาดใหญ่พอสำหรับการกดด้วยนิ้ว
- แสดงยอดรวมขนาดใหญ่ตลอดเวลา
- แยกพื้นที่ซ้าย (รายการสินค้า) และขวา (ออเดอร์)
