# Flow — Module: ขาย / บิล

## ภาพรวม
Module หลักของ POS ครอบคลุมการสร้างออเดอร์, เลือกสินค้า, ใช้โปรโมชัน, เลือกลูกค้า, รับชำระเงิน, และออกบิล

---

## Flow 1: ขายปกติ (Cash Sale)

```
[หน้าขาย] — ต้องเปิดกะก่อน
  │
  ▼
เลือกสินค้า:
  ├─ กดสินค้าจากรายการ / Grid
  ├─ ค้นหาด้วยชื่อหรือบาร์โค้ด
  └─ สแกนบาร์โค้ด
  │
  ▼
ออเดอร์แสดงรายการสินค้า:
  ├─ ปรับจำนวน (+/-)
  ├─ ลบรายการ
  └─ เปลี่ยนหน่วยขาย (ชิ้น/แพ็ค/ลัง)
  │
  ▼
เลือกลูกค้า (ไม่บังคับ):
  ├─ "ลูกค้าทั่วไป" (default)
  └─ ค้นหาสมาชิกด้วยเบอร์โทร
  │
  ▼
ระบบคำนวณยอด:
  ├─ ราคารวม (ราคาปกติ)
  ├─ ส่วนลดโปรโมชัน
  ├─ ยอดสุทธิ
  └─ ใช้แต้มแลกส่วนลด (ถ้าเป็นสมาชิก)
  │
  ▼
เลือกวิธีชำระ:
  ├─ เงินสด → กรอกจำนวนที่รับ → คำนวณทอน
  ├─ โอนเงิน / พร้อมเพย์ → กรอกยอดโอน
  └─ ผสม (เงินสด + โอน)
  │
  ▼
กด "รับเงิน" / "ยืนยัน"
  │
  ├─ [สำเร็จ] → บิลถูกบันทึก → สต็อกถูกตัด (FEFO อัตโนมัติ) → พิมพ์/แสดงบิล
  │              ระบบเลือก lot expiry ใกล้สุดก่อน + บันทึก lot_id ต่อ OrderItem
  └─ [ยอดไม่ครบ] → แจ้งเตือน "ยอดไม่ตรง"
```

## Flow 2: ขายสินค้าเป็นชุด (Bundle)

```
[หน้าขาย]
  │
  ▼
เลือกสินค้าชุด (โปรชุด)
  │
  ▼
ระบบเพิ่มสินค้าในชุดทั้งหมดเข้าออเดอร์
ราคาคิดตามราคาชุด (ไม่ใช่รวมรายชิ้น)
  │
  ▼
ดำเนินการต่อเหมือน Flow 1
```

---

## Flow 3: ยกเลิกบิล

```
[ประวัติบิล] → เลือกบิลที่ต้องการยกเลิก
  │
  ▼
กด "ยกเลิกรายการ"
  │
  ▼
[ยืนยันการยกเลิก]
  ├─ ยืนยัน → บิลถูกยกเลิก → สต็อกคืน → บันทึกเหตุผล
  └─ ยกเลิก → ออกจาก dialog
```

---

## Flow 4: บิลค้างชำระ (Credit)

```
[หน้าขาย] → สร้างออเดอร์ตามปกติ
  │
  ▼
กด "บันทึกค้างชำระ"
  │
  ▼
ระบุลูกค้า (บังคับ) + หมายเหตุ
  │
  ▼
บันทึก → สต็อกถูกตัด → บิลสถานะ "ค้างชำระ"
  │
  ▼
[ภายหลัง] ลูกค้ามาชำระ → เลือกบิลค้างชำระ → รับชำระ → บิลสำเร็จ
```

---

## Flow 5: รับเงินสด (Cash Count / Exchange)

```
[ระหว่างขาย] ลูกค้าให้เงินมาและต้องทอน:
  │
  ├─ กรอกจำนวนรับ → ระบบคำนวณทอน
  ├─ กด "แลกเงิน" → แลกธนบัตร/เหรียญ
  └─ "ทอนสด" / "ทอนเงินสดคืนลูกค้า"
```

---

## Flow 6: ค้นหาและดูประวัติบิล

```
[ประวัติการออกบิล]
  │
  ├─ ค้นหาด้วยเลขบิล
  ├─ กรองด้วยวันที่
  ├─ กรองด้วยสถานะบิล (สำเร็จ/ค้างชำระ/ยกเลิก)
  └─ กรองด้วยพนักงานที่ขาย
  │
  ▼
เลือกบิล → ดูรายละเอียดบิล
  ├─ พิมพ์บิลซ้ำ
  ├─ ยกเลิกบิล (ถ้าสิทธิ์อนุญาต)
  └─ ดูข้อมูลสมาชิกที่เชื่อมโยง
```

---

## Edge Cases
| สถานการณ์ | การจัดการ |
|-----------|-----------|
| สินค้าหมดสต็อก | แจ้งเตือน ไม่บล็อกการขาย (ขายติดลบได้ถ้าตั้งค่าอนุญาต) |
| ยอดโอนน้อยกว่าที่ควร | แจ้ง "ลูกค้าโอนขาด" — บันทึกได้แต่ต้องระบุหมายเหตุ |
| ยอดโอนมากกว่า | แจ้ง "ลูกค้าโอนเกิน" — บันทึกได้ |
| ไม่ได้เปิดกะ | บล็อกการขาย แจ้ง "ยังไม่เปิดกะ" |
| เน็ตล่มระหว่างขาย | draft order เก็บไว้ใน local — sync เมื่อออนไลน์ |
