### 1. ข้อมูลทางเทคนิคของระบบ (Technical Specification)

- **Platform:** Web Application รองรับการใช้งานผ่าน Google Chrome และ Safari
- **Responsive Design:** ออกแบบ Interface ให้ใช้งานง่ายทั้งบน Desktop, Tablet และ Smartphone
- **Connectivity:** ระบบทำงานรูปแบบ Cloud-Based (ต้องเชื่อมต่ออินเทอร์เน็ตในการใช้งาน)
- **Localization:** รองรับภาษาไทยเต็มรูปแบบ

---

### 2. โมดูลหลักของระบบ (System Modules)

#### Module 1: ใบเสนอราคา (Quotation)

ระบบสร้างและจัดการใบเสนอราคาอย่างครบวงจร รองรับการทำงานบนทุกอุปกรณ์

- **Multi-device Support:** สร้างและกรอกข้อมูลได้อย่างรวดเร็ว ผ่านอุปกรณ์ที่หลากหลายทั้ง PC / Tablet / Mobile
- **Product Auto-fill:** กรอกข้อมูลรายละเอียดสินค้าได้ทันที ไม่ต้องกรอกใหม่ทุกครั้งที่สร้างใบเสนอราคา
- **Real-time Stock & History:** แสดงข้อมูลสต๊อกปัจจุบัน และข้อมูลประวัติผู้ค้าเดิมได้ทันที
- **Expiry Alert:** แจ้งเตือนใบเสนอราคาที่ยังไม่มีใบสั่งซื้อภายในเวลาที่กำหนด
- **Price Approval Workflow:** หากพนักงานขายแก้ไขราคาให้ต่ำกว่าราคาขั้นต่ำที่บริษัทกำหนด ระบบบล็อกการออกใบเสนอราคาและแจ้งเตือนผู้บริหารเพื่ออนุมัติก่อน

#### Module 2: บริหารลูกค้า (Customer Management)

จัดเก็บและวิเคราะห์ข้อมูลลูกค้าอย่างเป็นระบบ เพื่อป้องกันข้อมูลรั่วไหลและสนับสนุนการตัดสินใจทางธุรกิจ

- **Customer Profile:** น้ำเข้าข้อมูลลูกค้าจาก EASY ACC
- **Gold Customer Report:** ผลสรุปรายชื่อลูกค้าที่มีการเปิดใบสั่งซื้อสูงที่สุด และรายชื่อลูกค้าทองคำที่มียอดสั่งซื้อสูงที่สุด

#### Module 3: บริหารพนักงานขาย (Sales Team Management)

ติดตามและวัดผลการทำงานของทีมขาย พร้อมควบคุมสิทธิ์การเข้าถึงข้อมูลตามบทบาทหน้าที่

- **Employee Profile:** ชื่อนามสกุล ตำแหน่งงาน
- **Role-based Access Control:** พนักงานแต่ละคนมีสิทธิ์การเข้าถึงข้อมูลแตกต่างกันตามบทบาทหน้าที่ เมื่อพนักงานลาออกจะถูกลบบัญชีออกจากระบบทันที ไม่สามารถเข้าใช้งานได้อีก
- **Work History:** ประวัติการทำงาน รายการใบเสนอราคาที่รับผิดชอบ รายชื่อลูกค้าที่ดูแล และข้อมูลการเข้าพบลูกค้า
- **Performance Summary:** ผลสรุปรายชื่อพนักงานที่มีใบเสนอราคาที่รับผิดชอบมากที่สุด และรายชื่อพนักงานที่มีอัตราส่วนการปิดยอดใบเสนอราคาสูงที่สุด

#### Module 4: ข้อมูลสต๊อก (Inventory Management)

จัดการข้อมูลสินค้าและติดตามความเคลื่อนไหวของสต๊อก

- **Product Catalog:** รองรับการนำเข้าข้อมูลจาก Easy ACC
- **Quotation Linkage:** เชื่อมโยงกับใบเสนอราคา
- **Stock Analysis:** ผลสรุปข้อมูลยอดสินค้าขายดี หรือสต๊อกที่เคลื่อนไหวช้า

#### Module 5: รายงานทำงานของพนักงานขาย (Sales Report)

บันทึกการทำงานภาคสนามของพนักงานขาย เชื่อมโยงกับใบเสนอราคา และใบทดลองสินค้า

- **Daily Work Plan:** ใบรายงานสำหรับพนักงานขายกรอกข้อมูล เพื่อวางแผนการทำงานในแต่ละวัน ระบุค่าใช้จ่ายที่เกิดขึ้นจากการเดินทาง
- **Visit Verification:** บันทึกการเข้าพบลูกค้าจริงหรือไม่ พร้อมแนบหลักฐานรูปภาพ
- **Performance Tracking:** ติดตามการทำงานโดยเชื่อมโยงกับใบเสนอราคาและใบสั่งซื้อที่เกิดขึ้นในช่วงเวลาการทำงาน
- **Customer Followup Tracking:** ติดตามการสื่อสารกับลูกค้าทั้งลูกค้าเก่า/ใหม่ ตามลิสที่ได้มอบหมายให้กับเซล
- **Test Report:** รายงานติดตามการเทสสินค้าของลูกค้า

#### Module 6: การแจ้งเตือน (Notification)

ระบบแจ้งเตือนอัตโนมัติเพื่อให้ผู้บริหารติดตามสถานะได้ทันทีโดยไม่ต้องเข้าหน้าเว็บตลอดเวลา

- **Multi-channel Notification:** แจ้งเตือนผ่านอีเมลและไลน์เป็นหลัก เมื่อมีการสร้างใบงานใหม่ เมื่อใบเสนอราคาค้างนานเกินกำหนด หรือมีใบเสนอราคาที่เข้าเงื่อนไขต้องอนุมัติ

#### Module 7: กิจกรรมของฉัน (My Activities)

หน้ารวมงานที่ผู้ใช้ต้องดำเนินการ ช่วยให้ไม่มีงานตกหล่น

- **Personal Task Dashboard:** ตรวจสอบงานที่ผู้ใช้ต้องดำเนินการ เช่น ใบเสนอราคาของฉันที่ยังไม่มีใบสั่งซื้อ

#### Module 8: แดชบอร์ดผู้บริหาร (Executive Dashboard)

สรุปภาพรวมการทำงานทั้งหมดของระบบสำหรับผู้บริหาร

- **Overview Summary:** สรุปภาพรวมการทำงานทั้งหมดของระบบ
- **Alert Overview:** ภาพรวมการแจ้งเตือนใบเสนอราคาที่ยังไม่มีการสร้างใบสั่งซื้อ ใบสั่งซื้อที่ใกล้ถึงกำหนดชำระเงิน และสถานะที่สำคัญอื่น ๆ

#### Module 9: AI Automation Workflow

ระบบ AI ช่วยวิเคราะห์และสรุปข้อมูลเชิงลึกอัตโนมัติ เพื่อสนับสนุนการตัดสินใจของผู้บริหาร

- **Quotation Weekly Summary:** AI สรุปภาพรวมใบเสนอราคาประจำสัปดาห์ วิเคราะห์แนวโน้ม อัตราการปิดยอด และให้คำแนะนำเชิงกลยุทธ์แก่ทีมขาย
- **Customer Behavior Analysis:** AI วิเคราะห์พฤติกรรมลูกค้า ตรวจจับลูกค้าที่ยอดสั่งซื้อหายไปหรือสั่งช้ากว่าปกติ และระบุกลุ่มลูกค้าที่มีโอกาสเติบโตสูง
- **Inventory Intelligence:** AI วิเคราะห์คลังสินค้า คาดการณ์ความต้องการสินค้าล่วงหน้า ระบุสต๊อกที่เคลื่อนไหวช้า และแนะนำการจัดการสต๊อกให้มีประสิทธิภาพ
